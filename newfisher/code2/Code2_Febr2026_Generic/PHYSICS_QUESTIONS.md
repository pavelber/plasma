# Code2 (Co2feb26): возможные изменения физики (на будущее)

Два ограничения в коде, которые автор ввёл, чтобы уменьшить время счёта и не
получать очень маленьких чисел. Их можно отменить, но это **пока не сделано**:
результаты изменятся, и возможны проблемы — рост времени счёта, деление на очень
малые величины (или на ноль) и т.п. Если будем делать, то отдельным шагом, с
проверкой этих проблем и с явным обновлением эталонов тестов.

Номера строк — по файлу `Co2feb26_procs.for` (ноябрь 2026).

## 1. Отбор слабых линий убирает и радиационный распад из кинетики

`LineList`, строки 700–708: для пары уровней с f < fluMin, или A < AulMin, или
hv < hvMin выполняется `A(k2,k,nX) = zero`. Массив A используется и в `PMg0`
(строки 2555, 2575) как скорость спонтанного распада, поэтому эти переходы
исчезают не только из спектра, но и из уравнений для заселённостей.

Сколько обнуляется (сравнение A до и после `LineList`):

| | Kr (AulMin = 3e9, fluMin = 0.003) | Ge (AulMin = 3e5, fluMin = 0.003) |
|---|---|---|
| переходов с A > 0 в базе | 39 727 | 121 726 |
| обнулено | 31 715 (80%) | 114 043 (94%) |
| из них с A > 1e10 1/s | 4 390 | 13 151 |
| из них с A > 1e12 1/s | 333 | 1 986 |
| самый большой удалённый A | 1.0e14 1/s (hv = 16.6 кэВ) | 3.7e13 1/s (hv = 10.1 кэВ) |

Как можно сделать: обнулять A только в копии для спектра (или помечать линию как
«не в спектре»), а в `PMg0` использовать исходный A.

## 2. Поглощение в линии отключается по заселённости верхнего уровня

`EmiAbso`, строка 873: `if(POPi(kU,nX,La) .LT. 1.d-15) goto 1` пропускает и
излучение, и поглощение линии. Поглощение пропорционально заселённости нижнего
уровня, поэтому для поглощения можно проверять POPi(kL), а для излучения —
POPi(kU).

## Решено не менять

Опечатка dv/v в Params1.inp для Kr (1540, 1,e-3), пропуск кинетики при
ne < 1e15, первые два шага без BB-излучения, крылья линий ±30%, разные проверки
порога BEk в EmiAbso и Ws.
