Code2 (Co2feb26), версия Generic: как запускать на разных элементах
====================================================================

Одна и та же программа Co2feb26_Generic_v3.exe считает любой элемент. Перекомпилировать
под элемент не нужно: размеры массивов программа берёт из входных файлов при запуске.
Программа рассчитана на 4 элемента: основной элемент X (Kr, Ge, ...) плюс C, He, D.
Кинетика, линии и фотоионизация считаются только для X.

Нужен Windows 10 или 11 (64 бит). Ничего устанавливать не надо: exe самодостаточный.


1. ВХОДНЫЕ ФАЙЛЫ
----------------

Для каждого расчёта нужна отдельная папка со всеми входными файлами (имена те же,
что у прежней версии программы; регистр букв не важен):

  Params0.inp   размеры базы (см. ниже)
  Params1.inp   параметры расчёта: массы ионов, fluMin, AulMin, сетка по hv и т.д.
  Params2.inp   сценарий: время, радиусы зон, плотности, температуры
  QSs.inp       уровни элемента X
  QSsC.inp, QSsHe.inp, QSsD.inp   уровни C, He, D
  Exc.inp       возбуждение элемента X
  Inz.inp       ионизация элемента X
  AIw.inp       автоионизация элемента X
  InpResp1.inp ... InpResp9.inp   спектральный отклик детекторов

Формат всех файлов тот же, что у прежней версии. Число точек в InpResp*.inp можно
менять: программа считает их сама.

Params0.inp. Первые четыре строки - по четыре числа для X, C, He, D:
  строка 1  FSS  первый спектроскопический символ в базе каждого элемента
  строка 2  HSS  спектроскопический символ H-подобного иона
  строка 3  Nnu  номер уровня ядра в QSs-файле
  строка 4  NST  число уровней в базе
  строка 5  разделитель
  строки 6-8  число строк в Exc.inp, Inz.inp, AIw.inp (включая заголовок)
По строкам 2 и 4 программа выделяет память: nQSm = максимум NST, HSSm = максимум HSS.

Params0.inp можно построить автоматически по QSs*.inp, Exc.inp, Inz.inp, AIw.inp
скриптом tools\create_params0.py (нужен Python 3):

  python tools\create_params0.py "C:\путь\к\папке\элемента"

Старый Params0.inp при этом переименовывается в Params0.inp.old. Скрипт проверен на
базах Kr и Ge: выдаёт те же числа, что в их Params0.inp. Комментарии в строках он
пишет одинаковые для всех элементов (там упомянут Ge) - на расчёт они не влияют.

Примеры полных наборов входных файлов: папки examples\Kr и examples\Ge.


2. ЗАПУСК
---------

Скопировать Co2feb26_Generic_v3.exe в папку с входными файлами и запустить его там.
В окне PowerShell (пример для Ge):

  cd "C:\Code2\examples\Ge"

  .\Co2feb26_Generic_v3.exe

В начале программа печатает размеры, взятые из Params0.inp, и нужную память:

  Params0.inp: nQSm = max(NST) =  1107,  HSSm = max(HSS) =  32;  arrays ~  0.44 GB

Память: примерно 356 * NST^2 байт (0.44 ГБ для NST = 1107, 0.93 ГБ для 1612,
1.9 ГБ для 2300). Прежнего ограничения NST < 2300 нет - есть только объём памяти.

Число ядер. По умолчанию программа занимает все ядра процессора. Чтобы оставить
часть машины свободной, перед запуском задать число потоков, например 8:

  $env:OMP_NUM_THREADS = 8

Результат от числа потоков не зависит.

Короткая проверка входных файлов. В Params2.inp, строка 5 - время окончания
(StopTime). Если временно поставить там 1.d-12, программа сделает один шаг по
времени (около 20 с для Kr) - так быстро видно, что входные файлы читаются.
Полный расчёт до 65 пс на 20 ядрах: Kr около 6 мин, Ge около 5 мин.


3. ЧТО ПРОГРАММА ПИШЕТ
----------------------

  *.dat         результаты, как в прежней версии (тот же формат)
  Timing.log    время работы частей программы на каждом шаге (новое)
  Warnings.log  появляется, только если сработала проверка ошибки (новое)

Выходные .dat записываются на диск только в конце расчёта. Если расчёт прервать
(или компьютер уснёт и программа будет остановлена), они останутся пустыми.
Во время длинного расчёта компьютер лучше не усыплять.

Если программа нашла ошибку во входных данных, она печатает сообщение и пишет его
в Warnings.log, затем ждёт, что пользователь введёт go (продолжить) или что-то
другое (остановить). Если программа запущена без клавиатуры (из скрипта), она
останавливается с кодом выхода 1.


4. ЧТО ФИКСИРОВАНО В ПРОГРАММЕ (не зависит от элемента)
--------------------------------------------------------

  4 элемента (X, C, He, D), 3 зоны (BS, Core, Capsule), не больше 16000 точек
  сетки по hv, 8 кадров спектра, 9 детекторов. Из каждого InpResp*.inp читаются
  не больше 5000 точек. Если сетка по hv из Params1.inp получится больше 16000 точек,
  программа остановится с сообщением.


5. ПЕРЕСБОРКА (только если меняется сам код)
--------------------------------------------

Нужен GNU Fortran, например WinLibs (вместе с ним ставится mingw32-make):

  winget install BrechtSanders.WinLibs.POSIX.UCRT

Затем в папке с исходниками:

  mingw32-make -f Makefile.gnu

Тесты (нужен Python 3; проверяют, что результаты не изменились ни в одном бите):

  mingw32-make -f Makefile.gnu test

  mingw32-make -f Makefile.gnu test-e2e

Первая команда - быстрые тесты (около 30 с), вторая - 3 шага настоящей программы
для Kr и Ge (около 70 с на 20 ядрах).
